برنامه‌ریز پرنسسی درس
=====================

اجرا:
1) فایل index.html را باز کنید.
2) درس‌ها، زمان شروع، مدت مطالعه، استراحت و تعداد دور را تنظیم کنید.
3) روی «برنامه‌ام را بساز» بزنید.

ذخیره اطلاعات:
- اطلاعات با localStorage در همان مرورگر ذخیره می‌شود.
- با بستن و باز کردن دوباره صفحه، تنظیمات باقی می‌ماند.
- اگر داده‌های مرورگر پاک شود یا از مرورگر دیگری استفاده کنید، اطلاعات قبلی قابل دسترس نیست.

نصب مثل اپ روی موبایل:
- برای قابلیت PWA و آفلاین، پوشه را روی یک هاست HTTPS قرار دهید.
- سپس در مرورگر موبایل گزینه Add to Home Screen / Install App را بزنید.

فایل‌ها:
index.html
style.css
app.js
manifest.webmanifest
sw.js
