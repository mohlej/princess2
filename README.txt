برنامه‌ریز پرنسسی — نسخه ۳ 💗
================================

یک سایت کامل و مستقل برای درس‌خواندن با پشتیبانی از موبایل و دسکتاپ.
برای اجرا نیازی به سرور برنامه، دیتابیس یا نصب کتابخانه نیست؛ فقط فایل‌ها
را روی GitHub Pages منتشر کنید.

ویژگی‌ها
--------
۱. برنامه‌ریز روزانه: دروس، دورهای مطالعه، استراحت، زمان‌بندی، وضعیت الان.
۲. پومودورو: مطالعه، استراحت کوتاه و بلند، زمان‌های دلخواه، مکث و ادامه، زنگ پایان.
۳. چک‌لیست: اضافه‌کردن، اولویت‌بندی، تعیین تاریخ، ویرایش، انجام و حذف کارها.
۴. تقویم مطالعه شمسی: نمایش فعالیت‌ها، مطالعه، کارها و امتحان‌ها در هر روز.
۵. آمار و نمودار: مجموع امروز، هفت روز و سی روز، نمودار ۷/۳۰ روزه و تاریخچه جلسات.
۶. زنجیره موفقیت: تعداد روزهای متوالی مطالعه، بهترین رکورد و نشان‌های ۱، ۳، ۷، ۱۴ و ۳۰ روز.
۷. دفترچه یادداشت: ثبت، جستجو، ویرایش و حذف یادداشت‌های شخصی.
۸. امتحان‌ها: اضافه‌کردن تاریخ و ساعت امتحان، ویرایش، حذف و شمارش معکوس زنده.
۹. چند پروفایل محلی: مدیریت اطلاعات متفاوت برای کاربران یک مرورگر.
۱۰. پشتیبان‌گیری/بازیابی: دانلود یا واردکردن فایل JSON برای هر پروفایل.

حفظ اطلاعات و حریم خصوصی
------------------------
- اطلاعات هر مرورگر/دستگاه به‌طور مستقل در localStorage ذخیره می‌شود.
- در یک مرورگر مشترک می‌توان از فهرست پروفایل‌ها، پروفایل‌های متفاوت ایجاد کرد.
- پروفایل‌ها حساب کاربری امن نیستند و رمز ورود ندارند: دیگر افرادی که به همان
  مرورگر و دستگاه دسترسی دارند، می‌توانند پروفایل‌ها را انتخاب کنند.
- سایت روی GitHub Pages پایگاه داده ندارد؛ هیچ اطلاعات شخصی روی GitHub آپلود نمی‌شود.
- اطلاعات در مرورگر دیگری/گوشی دیگری به شکل خودکار ظاهر نمی‌شود.
- برای جابه‌جایی بین دستگاه‌ها، از گزینه «پشتیبان» در دستگاه اول و «بازیابی»
  در پروفایل دستگاه دوم استفاده کنید (انتقال دستی).
- پاک شدن داده‌های مرورگر می‌تواند اطلاعات را حذف کند؛ مرتباً پشتیبان بگیرید.
- انتقال خودکار با حساب و رمز به بک‌اند و احراز هویت، مثلاً Supabase یا Firebase، نیاز دارد.
- هنگام اولین ارتقا، اطلاعات برنامه‌ریز و پومودورو از نسخه قدیمی همان مرورگر
  به اولین پروفایل جدید کپی می‌شود؛ داده‌های قبلی پاک نمی‌شوند.

آمار چگونه محاسبه می‌شود؟
-------------------------
- تنها جلسات مطالعه کامل‌شده در پومودورو و مطالعه‌های ثبت‌شده با فرم دستی حساب می‌شوند.
- صرفاً ساخت برنامه روزانه به معنی انجام مطالعه نیست.
- یک روز با دست‌کم یک جلسه مطالعه ثبت‌شده (با دقیقه مثبت) روز فعال حساب می‌شود.
- زنجیره روزهای پی‌درپی فعال تا امروز، یا اگر امروز هنوز مطالعه نکرده‌اید، تا دیروز است.
- ثبت دستی مطالعه برای روزهای آینده مجاز نیست.
- جلسه‌های مطالعه اشتباهی را می‌توان از بخش آمار حذف کرد.

آپلود روی GitHub Pages
----------------------
۱. فایل ZIP را در رایانه Extract / استخراج کنید.
۲. به مخزن https://github.com/mohlej/princess2 بروید و شاخه main را باز کنید.
۳. از Add file > Upload files استفاده کنید.
۴. فایل‌های داخل ZIP (نه خود ZIP و نه یک پوشه اضافه) را در ریشه مخزن بارگذاری کنید.
۵. در صورت وجود فایل‌های هم‌نام، آن‌ها باید با نسخه‌های جدید جایگزین شوند.
۶. Commit changes را بزنید.
۷. از Settings > Pages بررسی کنید انتشار روی main / (root) تنظیم شده باشد.
۸. پس از سبز شدن Deploy در بخش Actions سایت را باز کنید:
   https://mohlej.github.io/princess2/
۹. اگر هنوز نسخه قدیمی دیده شد، Ctrl+Shift+R یا پنجره ناشناس را امتحان کنید.

محتویات نسخه جدید:
index.html            صفحه اصلی و همه تب‌ها
style.css             طراحی و واکنش‌گرایی
app.js                برنامه‌ریز قبلی
pomodoro.js           پومودورو + ثبت دوره‌های کامل در آمار
hub.js                شش قابلیت جدید
data.js              پروفایل‌ها، انتقال اطلاعات قدیمی، پشتیبان
tabs.js              مدیریت تب‌ها
sw.js                 کش آفلاین و به‌روزرسانی فایل‌ها
manifest.webmanifest  مشخصات وب‌اپ
README.txt            این راهنما

محدودیت صدای پس‌زمینه
--------------------
در دسکتاپ هنگام بازبودن تب، تلاش می‌شود زنگ پایان به‌موقع پخش شود؛
اما بسته‌شدن تب/مرورگر، Sleep سیستم و محدودیت باتری مرورگرهای موبایل می‌تواند
صدای هشدار را متوقف یا با تأخیر پخش کند. برای هشدار حتماً ابتدا دکمه شروع
یا تست صدا را بزنید تا اجازه‌ی پخش صدا فراهم شود.
